## 🎮 Overview

BSManager installs and switches between multiple Beat Saber versions, manages mods and maps, and handles all game file operations without touching the Steam installation.

Whether you're a newcomer or a veteran, BSManager provides the tools you need to get the most out of your gaming mods experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Multi-Version** | Install and switch between any Beat Saber game version |
| **Mod Installer** | One-click install of BeatMods-listed mods with dependency resolution |
| **Map Downloader** | Search and install custom song maps from BeatSaver |
| **Isolated Versions** | Each game version has its own isolated mods and maps folder |
